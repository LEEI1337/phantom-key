ESP-Key Configurator

Nicht verbunden

So geht's:

  1. ESP-Key per USB an den PC anschließen
  2. Auf "USB Verbinden" klicken
  3. Im Popup den USB-Port auswählen (z.B. "USB Serial" oder "ttyACM0")
  4. Makros und LEDs konfigurieren
  5. Speichern nicht vergessen!

Makro-Tasten

Befehle: STRING, DELAY, ENTER, CTRL, ALT, WIN/GUI, SHIFT, F1-F12

LED-Einstellungen

255
50
50

Ducky Script Befehle

STRING text     - Text tippen
DELAY 500       - 500ms warten
ENTER           - Enter-Taste
TAB             - Tab-Taste
ESCAPE          - Escape-Taste

CTRL c          - Strg+C (Kopieren)
CTRL v          - Strg+V (Einfügen)
ALT TAB         - Alt+Tab
WIN r           - Windows+R
SHIFT a         - Shift+A

F1 bis F12      - Funktionstasten
UP/DOWN/LEFT/RIGHT - Pfeiltasten

Tasten-Kombinationen

1 + 2  = Farbe heller
1 + 3  = Farbe dunkler
1 + 4  = Helligkeit +
1 + 5  = Helligkeit -
1 + 6  = Effekt wechseln
1 + 7  = An/Aus
1 + 9 (3s) = Config Mode
